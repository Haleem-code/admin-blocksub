BlockSub Admin Dashboard

Overview

The BlockSub Admin Dashboard is a powerful web-based interface for managing and monitoring all the platforms that are using the BlockSub SDK. This dashboard provides insights into each platform's performance, tracks their usage of the SDK, and monitors the overall revenue generated by BlockSub across all platforms. This tool is essential for administrators and decision-makers who want to stay updated on how BlockSub is performing and where improvements can be made.

Key Features

1. Platform Management:

List all platforms that have integrated the BlockSub SDK.

View detailed information about each platform (name, URL, subscription model, etc.).

Track the number of active subscriptions on each platform.

View usage metrics for each platform, including API requests and active users.

Activate or deactivate platforms from using the SDK.



2. Revenue Tracking:

Monitor total revenue generated by all platforms.

Track individual platform revenue and contribution to the overall BlockSub revenue.

View revenue trends over specific periods (daily, weekly, monthly).

Generate revenue reports and export them in different formats (CSV, PDF).



3. Analytics Dashboard:

Real-time data visualization of platform performance (graphs, charts, and metrics).

Filter data by time periods, platform name, and other relevant parameters.

Track SDK usage statistics like API calls, user sign-ups, and active subscriptions.

Identify top-performing platforms and trends in SDK usage.




4. User Roles and Permissions:

Manage admin roles and permissions.

Assign access control based on team roles (Admin, Finance, Marketing, etc.).

Provide read-only access to certain dashboards for specific users.



5. Reports and Exports:

Generate detailed reports for revenue, platform usage, and SDK performance.

Export data for further analysis in external tools or for reporting purposes.
